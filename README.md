# 🧱 Mojang API

Mojang API is a **client** for Minecraft profile endpoints: **UUID** lookup, **name history**, and **skin textures**. It caches results and handles **429** responses.

## 🚀 Why Choose Mojang API?

Profile endpoints throttle quickly, and repeated lookups are the norm. Caching plus backoff keeps a name checker usable without constant failures.

Responses are typed, so a missing profile is an error case rather than an exception in the caller.
